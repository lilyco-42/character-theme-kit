# Character Theme Kit

101 个热门动漫角色桌面主题素材包 — 鼠标指针、4K壁纸、UI组件配色。

## 内容

| 品类 | 数量 | 说明 |
|---|---|---|
| 角色主题 | 101 | 火影/海贼/鬼灭/咒术/巨人/龙珠/EVA/原神/SAO/电锯人/Vocaloid 等 |
| 鼠标指针 .cur | 303 | 每角色 arrow/hand/wait 三种，.cur/.ico/.svg |
| 4K壁纸 | 101张 | 1920×1080，抽象配色+符号 |
| UI组件 CSS | 101套 | 按钮/卡片/输入/开关/进度/徽章 |
| 配色token | 101份 | palette.json |
| 字体主题说明 | 101份 | fonts.md |
