# 带土 · 字体主题

**系列**: 火影忍者
**气质**: 土褐·假面

## 推荐字体搭配

| 用途 | 字体 | 备选 |
|---|---|---|
| 标题（中） | 思源黑体 Heavy | 站酷高端黑 |
| 标题（英） | Orbitron / Rajdhani | Russo One |
| 正文（中） | 思源黑体 Regular | 苹方 |
| 正文（英） | Inter | Roboto |
| 代码/数据 | JetBrains Mono | Fira Code |

## 排版规范

- 主标题字号: 32-48px，字重 800
- 副标题: 18-24px，字重 600
- 正文: 14-16px，行高 1.6
- 强调色文字: #DC2626
- 主色用于标题/品牌: #7C2D12

## 色彩 Token

```css
--primary: #7C2D12;
--secondary: #1C1917;
--accent: #DC2626;
--electric: #F97316;
```
